# Fridge Kingdom

A wordless animated series about a tiny kingdom inside a fridge. New episode daily on YouTube: [@fridgekingdomm](https://www.youtube.com/@fridgekingdomm).

- `story/bible.md`: cast, rules, episode log, open threads
- `story/weekN.md`: each week's 7-episode script
- `episodes/`: one animation + sound script per episode
- `engine/`: shared drawing and sound helpers
- `CLAUDE.md`: the daily production runbook
